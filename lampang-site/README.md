# ランパーン留学 サイト

タイ・ランパーン病院への臨床留学を案内する1ページのサイトです（Astro・静的サイト）。

先輩の体験記はサイトには載せず、**オンライン面談をした人にだけ紹介する**方針です。
紹介用の体験記の管理には、Notion の「体験記データベース（サイト掲載用）」（留学体験記PJ ページの中）がそのまま使えます。

---

## 1. 手元で動かす
```bash
npm install
npm run dev      # http://localhost:4321 で確認
npm run build    # dist/ に公開用ファイルを書き出し
```

## 2. 公開する（Vercel の例）
1. このフォルダを GitHub のリポジトリに push する
2. Vercel で「Add New → Project」からそのリポジトリを読み込む（Framework は Astro が自動で選ばれます）
3. そのままデプロイする（相談フォームの送信先はコードに設定済みなので、環境変数は不要です）

以降は、GitHub に push するたびに自動で再デプロイされます。GitHub を使わない場合は、このフォルダで `vercel --prod` を実行しても更新できます。

Netlify / Cloudflare Pages でも、ビルドコマンド `npm run build`・公開フォルダ `dist` で同じように公開できます。

## 3. 相談フォームの送信先（Google フォーム）
サイトの相談フォームに入力された内容は、Google フォーム「ランパーン留学 相談フォーム」に届きます。
回答は Google フォームの「回答」タブで確認でき、スプレッドシートにも連携できます。

- **Google フォームは「公開」しておく必要があります。** 公開していないと、送信しても回答は届きません。
- 送信先は `src/components/Contact.astro` の先頭にある `endpoint`（`…/formResponse` の URL）です。
- サイトの各入力欄は、Google フォームの項目 ID（`entry.数字`）に対応させています。

| 入力欄 | Google フォームの項目 | entry |
|---|---|---|
| お名前 | お名前（必須） | `entry.862129124` |
| 所属・学年 | 所属・学年（必須） | `entry.1195187849` |
| メールアドレス | メールアドレス（必須） | `entry.1210582897` |
| 希望時期 | 希望時期 | `entry.848245008` |
| このページを知ったきっかけ | このページを知ったきっかけ（プルダウン） | `entry.681118877` |
| 相談したいこと・関心のあること | 相談したいこと・関心のあること | `entry.893536925` |
| オンライン面談を希望する | オンライン面談を希望する（チェック） | `entry.786577332` |

**Google フォームの質問を足す・直すとき**
- 質問を足す・消す・作り直すと、`entry` の番号が変わることがあります。変えたら、Google フォームの「︙ → フォームに事前入力する」を開き、ブラウザの検証ツールで各入力欄の `name="entry.…"` を確認して、`Contact.astro` の `name` を合わせてください。
- プルダウンの選択肢（「noteの記事」など）の文字は、サイト側の `<option>` と完全に一致させてください。ずれると回答が保存されません。

**仕様上の注意**
- 送信はブラウザから Google フォームへ直接行うため、サイト側では送信の成否を確認できません（通信エラーのときだけ失敗メッセージを表示します）。
- Google の公式機能ではない方法なので、Google 側の仕様変更で動かなくなる可能性が少しあります。定期的にテスト送信して確認してください。
- 別のサービス（Formspree など）に切り替えたい場合は、環境変数 `PUBLIC_FORM_ENDPOINT` にその URL を入れると上書きされます。ただしその場合は、入力欄の `name` もそのサービスの形式に合わせる必要があります。

## 4. 文言や写真を直したいとき

| 直したいところ | ファイル |
|---|---|
| ファーストビューの文言 | `src/components/Hero.astro` |
| ランパーン病院とは？ | `src/components/About.astro` |
| ランパーンってどんな街？ | `src/components/Town.astro` |
| 3つの特徴 | `src/components/Features.astro` |
| 留学までの流れ・留学の概要 | `src/components/Flow.astro` |
| よくある質問 | `src/components/Faq.astro` |
| 相談フォーム・窓口 | `src/components/Contact.astro` |
| 色 | `src/styles/global.css` の先頭（`--cta` が主色） |

`[ ]` で囲まれている箇所は仮置きです（受け入れ人数、写真の一言、フッターの表記など）。
